## Лабораторная работа № 2: Классы, агрегация и композиция

Реализованы базовые сущности курьерской службы в каталоге `src_cpp/`:
- `Cargo` (`cargo.hpp`, `cargo.cpp`) — груз, часть заказа (композиция).
- `Courier` (`courier.hpp`, `courier.cpp`) — курьер, независимый исполнитель (агрегация).
- `Order` (`order.hpp`, `order.cpp`) — заказ, связывающий груз и курьера.

### Сборка и запуск
```bash
g++ -std=c++17 src_cpp/main.cpp src_cpp/cargo.cpp src_cpp/courier.cpp src_cpp/order.cpp -o app
./app
```
